# IT Support & IT Operations Portfolio

Welcome to my practical IT Support and IT Operations portfolio.

This repository showcases hands-on training exercises completed as part of the **Kiron Skill IT Up programme**. The scenarios cover common IT support tasks, troubleshooting, user management and basic information security.

The portfolio demonstrates my developing practical skills in:

- User account and access management
- IT service requests and onboarding
- Basic security incident handling
- Technical documentation
